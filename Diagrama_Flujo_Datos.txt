┌──────────────────────────────────────────────────────────────────────────────┐
│ CAPA 5: FLUJO DE INTERACCIÓN (JAVASCRIPT)                                    │
└──────────────────────────────────────────────────────────────────────────────┘

    ESCENARIO 1: Usuario clickea tab "3º ESO"
    ─────────────────────────────────────────

    1. listener en .curso-tab[data-curso="3eso"]
         │
    2. JS busca CURSOS["3eso"].temas
         │
    3. Itera temas, genera HTML dinámico:
         │
         ├─ Asigna clase .color-3eso (color temático)
         ├─ Asigna cat: metodo/quimica/fisica
         ├─ Crear .unidad-ficha
         │  ├─ <img class="unidad-icono" src="imagenes/3ESO/0XA - Icono.webp">
         │  ├─ <span class="unidad-numero-texto1">0X</span>
         │  └─ <span class="unidad-nombre-texto2">Nombre del tema</span>
         │
    4. Inyecta en #grid-3eso (dentro de .unidades-grid)
         │
    5. Aplica animación: @keyframes fadeInUp (0.3s + delay por --d)
         │
    6. Asigna nuevo listener para click en cada ficha


    ESCENARIO 2: Usuario clickea unidad (ej: "La materia")
    ───────────────────────────────────────────────────────

    1. listener en .unidad-ficha
         │
    2. JS busca tema en CURSOS["3eso"].temas[2]
         │
    3. Extrae:
         ├─ nombre: "La materia"
         ├─ icono: "imagenes/3ESO/02A - Icono.webp"
         ├─ fondo: "imagenes/3ESO/02C - Imagen.webp"
         └─ enlaces: [ { label, tipo, url, editUrl } ]
         │
    4. Genera .modal (si no existe) o reutiliza:
         ├─ .modal-bg-img (src=fondo)
         ├─ .modal-hero-info
         │  ├─ .modal-icon-wrap (src=icono)
         │  └─ .modal-title
         │
    5. Genera .link-row × N (uno por enlace):
         │  ├─ <img class="link-row-icon">
         │  ├─ <span class="link-row-name">label</span>
         │  └─ <span class="link-row-type">tipo</span>
         │
    6. Busca icono en ICONOS{} y asigna img
         │
    7. Abre .modal-overlay (opacity 0→1)


    ESCENARIO 3: Generar datos de objetos
    ──────────────────────────────────────

    $ node sistema/generate-objetos.js
         │
    1. Lee imagenes/objetos/*.webp
         │
    2. Parsea nombre con REGEX: {Tema} - {Objeto} - A.webp
         │
    3. Crea entrada:
         {
           tema: "Energía",
           objeto: "Anillo termocrómico",
           categoria: "Física",
           icono: "imagenes/objetos/Energía - Anillo termocrómico - A.webp"
         }
         │
    4. Sobrescribe sistema/objetos-data.js

│ CAPA 7: SINCRONIZACIÓN Y ESTADO GLOBAL                                       │
└──────────────────────────────────────────────────────────────────────────────┘

    Clases de control (CSS):

    .active              ◄── Elemento UI seleccionado
    .selected            ◄── Unidad/tema activo (con ring glow)
    .tema-gris           ◄── Tema filtrado (grayscale 100%)
    .open                ◄── Modal abierto
    .en-unidad           ◄── Body class cuando estás dentro de tema

    Data attributes (para filtrado):

    [data-filter="metodo"]     ◄── Botón filtro categría
    [data-filter="fisica"]
    [data-filter="quimica"]
    [data-sort]                ◄── Ordenamiento
    [data-pub-filter]          ◄── Filtro publicaciones
    [data-juego-filter]        ◄── Filtro juegos
